# Identifying the customer's Rove camera

## Ask in this order

**1. "How many lenses does your camera have, and is there a lens facing inside the car?"**
- **One lens, front only** → R2-4K, R2-4K-USB-C, or R2-4K-PRO
- **Two lenses, both facing outside (front + rear)** → R2-4K-DUAL or R2-4K-DUAL-PRO
- **Three lenses (front, rear, and one facing interior/cabin)** → R3 [registry]

**2. "Is the screen a touchscreen, or does it have physical buttons?"**
- **Touchscreen, no physical buttons for menu** → R3 only [manual: r3-manual-website-files]
- **Physical buttons, NOT touch screen** → all R2 variants (R2-4K, R2-4K-USB-C, R2-4K-PRO, R2-4K-DUAL, R2-4K-DUAL-PRO) [manual: dc3831, manual: User Manual For New R2-4K, manual: ROVE_R2-4K_PRO_User_Manual_ManualsLib-mirror, manual: ROVE R2-4K Dual Dash Cam Instruction Manual, manual: ROVE-R2-4K-DUAL-PRO]

**3. "What type of charging port does it use—Mini-USB or USB-C?"**
- **Mini-USB** → original R2-4K only [manual: dc3831]
- **USB-C** → R2-4K-USB-C, R2-4K-PRO, R2-4K-DUAL, R2-4K-DUAL-PRO, or R3 [manual: User Manual For New R2-4K, manual: ROVE_R2-4K_PRO_User_Manual_ManualsLib-mirror, manual: ROVE R2-4K Dual Dash Cam Instruction Manual, manual: ROVE-R2-4K-DUAL-PRO, manual: r3-manual-website-files]

**4. "What size is the screen?"**
- **2.4 inch** → R2-4K, R2-4K-USB-C, or R2-4K-PRO [manual: dc3831, manual: User Manual For New R2-4K, manual: ROVE_R2-4K_PRO_User_Manual_ManualsLib-mirror]
- **3 inch** → R2-4K-DUAL or R2-4K-DUAL-PRO [manual: ROVE R2-4K Dual Dash Cam Instruction Manual, manual: ROVE-R2-4K-DUAL-PRO]

**5. "If you go to Wi-Fi settings on your phone, what network name appears?"**
- **"ROVE R2-4K-********"** → R2-4K [manual: dc3831]
- **"ROVE_R2-4K_*******"** → R2-4K-USB-C [manual: User Manual For New R2-4K]
- **"ROVE_R2-4K_PRO_*******"** → R2-4K-PRO [manual: ROVE_R2-4K_PRO_User_Manual_ManualsLib-mirror]
- **"ROVE_R2-4K-DUAL_PRO******"** → R2-4K-DUAL-PRO [manual: ROVE-R2-4K-DUAL-PRO]
- **"ROVE R3"** → R3 [manual: r3-manual-website-files]

## Model-by-model cues

**R2-4K (original, Mini-USB):**
- Mini-USB power (bottom right), not USB-C [manual: dc3831]
- 2.4" LCD screen, physical buttons only [manual: dc3831]
- WiFi SSID: "ROVE R2-4K-********" [manual: dc3831]
- Uses "ROVE" app only [manual: dc3831]
- Has a small built-in Li-ion battery, 250mAh (not a supercapacitor) [manual: dc3831]

**R2-4K-USB-C (newer):**
- USB-C power port [manual: User Manual For New R2-4K]
- 2.4" IPS display with LED above screen [manual: User Manual For New R2-4K]
- WiFi SSID: "ROVE_R2-4K_*******" [manual: User Manual For New R2-4K]
- Home screen shows live speed and compass [manual: User Manual For New R2-4K]

**R2-4K-PRO:**
- USB-C power [manual: ROVE_R2-4K_PRO_User_Manual_ManualsLib-mirror]
- 2.4" IPS display, red LED on top [manual: ROVE_R2-4K_PRO_User_Manual_ManualsLib-mirror]
- WiFi SSID: "ROVE_R2-4K_PRO_*******" [manual: ROVE_R2-4K_PRO_User_Manual_ManualsLib-mirror]
- Supercapacitor (no battery) [manual: ROVE_R2-4K_PRO_User_Manual_ManualsLib-mirror]
- Single lens rotates 360° [manual: ROVE_R2-4K_PRO_User_Manual_ManualsLib-mirror]

**R2-4K-DUAL:**
- 3" IPS display; two cameras (front + rear) in box [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
- USB-C power [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
- Dual-band 5G + 2.4G WiFi [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
- CPL filter and hardwire kit included [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]

**R2-4K-DUAL-PRO:**
- 3" IPS display; two USB-C ports (power + rear cam) [manual: ROVE-R2-4K-DUAL-PRO]
- WiFi SSID: "ROVE_R2-4K-DUAL_PRO******" [manual: ROVE-R2-4K-DUAL-PRO]
- 128GB card, CPL filter, and BOTH suction and sticky mounts included [manual: ROVE-R2-4K-DUAL-PRO]
- Home screen shows resolution like "2160P30+1440P30" [manual: ROVE-R2-4K-DUAL-PRO]
- Supercapacitor, no battery [manual: ROVE-R2-4K-DUAL-PRO]

**R3:**
- Three cameras: front, rear, and interior cabin with 4 hidden IR LEDs [manual: r3-manual-website-files]
- **ONLY touchscreen model** — press screen for menu, no physical buttons [manual: r3-manual-website-files]
- WiFi SSID: "ROVE R3" [manual: r3-manual-website-files]
- No reset button (unplug to reset) [manual: r3-manual-website-files]
- Supercapacitor ~2 second backup power [manual: r3-manual-website-files]

## If it still can't be pinned down

State clearly: "Based on what you've described, I cannot confirm the exact model. I'm going to give you general guidance that applies to most Rove cameras, but some steps may differ for your specific unit."

Do not guess. Proceed with general instructions while noting which steps require model-specific verification. Record the uncertainty in the case notes for follow-up.

**Not covered by the sources:** Wi-Fi network name pattern for R2-4K-DUAL; visual distinction between R2-4K-USB-C and R2-4K-PRO without Wi-Fi check; complete FCC ID listings for all models.
