# ROVE R3 (3-channel, touchscreen) — knowledge pack

## How to recognise this model

- **Three cameras**: front/main, interior/cabin (with 4 hidden IR LEDs around the lens), and rear camera [manual: r3-manual-website-files]
- **Touchscreen LCD**: press anywhere on screen to access Menu Settings; all navigation via touch, no physical buttons for menu [manual: r3-manual-website-files]
- **Mounting options**: suction mount OR magnetic sticky mount; sticky mount uses 3M adhesive with optional electrostatic film [manual: r3-manual-website-files]
- **Power connector**: USB Type-C port; requires ROVE USB Type-C HWK for parking mode (hardware kit not included) [manual: r3-manual-website-files]
- **Wi-Fi network name**: appears as "ROVE R3" in phone Wi-Fi settings; default password is 12345678 [manual: r3-manual-website-files]
- **No reset button**: unlike other models, unplugging and replugging power cable is the reset method [manual: r3-manual-website-files]
- **Supercapacitor** (not battery): holds charge for about 2 seconds [manual: r3-manual-website-files]
- **Model label**: referred to as "ROVE R3" or "R3" in documentation and Wi-Fi name [manual: r3-manual-website-files]

## Key facts

- **Power/battery**: Supercapacitor (not lithium battery); holds ~2 seconds of charge; must remain plugged in during operation; automatically records when powered on, stops and shuts off when power disconnected; Auto Power OFF saves last video file before shutting down [manual: r3-manual-website-files]
- **Memory card type**: Micro-SD (microSDXC), Class 10 or U3 speed only; max 512GB; ROVE Ultimate Micro SD Card recommended; format as MS-DOS (FAT) on Mac or FAT32 on Windows [manual: r3-manual-website-files]
- **Video resolutions**: 1440P (front), 1080P (cabin), 1080P (rear) — three-channel simultaneous recording [manual: r3-manual-website-files]
- **Wi-Fi band**: Not specified in sources
- **GPS**: Built-in; requires GPS signal lock for automatic date/time; GPS Player software available at www.rovedashcam.com for PC/Mac only [manual: r3-manual-website-files]
- **Parking mode requirements**: Requires ROVE Ultimate USB Type-C Hardwire Kit (HWK) installed to car fuse box; not included with camera [manual: r3-manual-website-files]
- **Operating temperature**: Above 140°F/60°C damages device; avoid direct sunlight and high temperatures [manual: r3-manual-website-files]
- **LED/indicators**: 
  - WiFi Status LED (on screen: HOME SCREEN shows "WiFi" icon and "WiFi Status LED")
  - Recording Status LED (on screen: "Recording Status LED")
  - IR LEDs: 4 hidden around cabin camera lens [manual: r3-manual-website-files]

## How-to procedures

### Power on/off
1. **Power on**: Connect power cable — camera automatically records when powered on [manual: r3-manual-website-files]
2. **Power off**: Disconnect power cable — camera stops recording, saves last file, and shuts off automatically [manual: r3-manual-website-files]

### Format the memory card
1. Press anywhere on LCD screen to access Menu Settings [manual: r3-manual-website-files]
2. Navigate to format option in System Settings (**DESTRUCTIVE**: all footage and data on card will be erased)

### Reset to defaults
- **There is no reset button** [manual: r3-manual-website-files]
- To resolve issues: unplug power cable, wait, then replug [manual: r3-manual-website-files]

### Set date/time and time zone
**Option A — Manual**:
1. Press anywhere on LCD screen to access Menu Settings
2. Go to System Settings > Date/Time
3. Select desired date and time manually [manual: r3-manual-website-files]

**Option B — Automatic via GPS**:
1. Ensure GPS signal lock is received
2. System will automatically set based on GMT/UTC value selection [manual: r3-manual-website-files]
3. Note: Camera does not use cloud services or IP connectivity for time [manual: r3-manual-website-files]

**Time Zone Setting**:
- Choose from three options in System Settings > Time Zone Setting [manual: r3-manual-website-files]

### Connect to phone app over Wi-Fi
1. Download and install ROVE APP from App Store or Google Play Store [manual: r3-manual-website-files]
2. Register for free account in app [manual: r3-manual-website-files]
3. On camera: turn ON WiFi via System settings > WiFi option, OR press WiFi icon on screen menu [manual: r3-manual-website-files]
4. On phone: go to Settings > WiFi > select "ROVE R3" WiFi network [manual: r3-manual-website-files]
5. Enter default password: **12345678**, then tap JOIN [manual: r3-manual-website-files]
6. Wait 10-15 seconds for notification pop-up [manual: r3-manual-website-files]
7. Open ROVE APP — camera will sync automatically [manual: r3-manual-website-files]

### Download/playback footage
**Method A — On camera (Playback Mode)**:
1. Access Playback Mode directly on camera touchscreen
2. Three folders available: front, cabin, and events [manual: r3-manual-website-files]
3. Use playback controls: reverse, play, fast forward, volume control [manual: r3-manual-website-files]

**Method B — Remove memory card**:
1. Gently push card edge inward until it clicks and pops out, then pull out [manual: r3-manual-website-files]
2. Insert into PC/Mac using memory slot or ROVE USB Type-C Card reader [manual: r3-manual-website-files]
3. Open with VLC Media Player: right-click file > Open With > VLC Media Player (or double-click if VLC is default) [manual: r3-manual-website-files]

**Method C — Via ROVE APP** (when connected via Wi-Fi):
- Camera syncs automatically; access through app interface [manual: r3-manual-website-files]

1. When engine turned off and HWK properly installed, camera enters parking mode automatically [manual: r3-manual-website-files]

**Collision detection alert**:
- When engine restarted, camera shows on-screen pop-up alert [manual: r3-manual-website-files]

## Troubleshooting playbook

### Wi-Fi: phone joins camera Wi-Fi then drops / "no internet"
- **Likely causes**: Apple devices may disconnect due to priority switching; phone detecting "no internet" on camera Wi-Fi and switching to cellular; camera Wi-Fi has no internet by design [manual: r3-manual-website-files]
- **Checks**:
  1. Check if iPhone: Apple devices prioritize networks differently
  2. Verify phone is staying on "ROVE R3" network and not auto-switching
  3. Check for "auto-join" or "auto-login" settings on phone
- **Fixes**:
  1. On iPhone: disable "Auto-Join" for other networks, or turn off cellular data temporarily
  2. Forget network and reconnect with password 12345678
  3. If persists: uninstall and reinstall ROVE APP, sign in, reconnect to R3 WiFi [manual: r3-manual-website-files]
- **Escalate**: If still dropping after app reinstall and phone settings adjusted

### Wi-Fi: camera Wi-Fi not in the list
- **Likely causes**: WiFi not enabled on camera; camera powered off; interference
- **Checks**:
  1. Verify camera is powered on and recording
  2. Check camera screen for WiFi icon status
  3. Try physically closer to camera
- **Fixes**:
  1. On camera: System settings > WiFi option, or press WiFi icon on screen menu to turn ON [manual: r3-manual-website-files]
  2. Unplug and replug power cable to restart camera
  3. Wait 10-15 seconds after enabling WiFi for network to broadcast
- **Escalate**: If WiFi icon shows ON but network never appears

### Wi-Fi: password rejected
- **Likely causes**: Wrong password entered; factory default changed; keyboard issue
- **Checks**:
  1. Confirm entering: **12345678** (eight digits)
  2. Check for extra spaces or auto-capitalization
  3. Try on second device to isolate phone issue
- **Fixes**:
  1. Re-enter carefully: 1-2-3-4-5-6-7-8
  2. **DESTRUCTIVE**: If password was changed and forgotten, no reset button exists — unplug/replug does not reset WiFi password; customer must remember or contact support for manual firmware update option
- **Escalate**: If default 12345678 rejected on multiple devices

### Wi-Fi: connection drops repeatedly
- **Likely causes**: Interference; distance; phone power saving; app issue
- **Checks**:
  1. Distance between phone and camera
  2. Other apps running in background
  3. Whether it happens during download vs. idle
- **Fixes**:
  1. Move phone closer to camera
  2. Close and restart ROVE APP
  3. Uninstall and reinstall ROVE APP, sign in and reconnect [manual: r3-manual-website-files]
  4. Restart phone
- **Escalate**: If reinstalling app doesn't resolve

### Wi-Fi: playback/download very slow
- **Likely causes**: Large file sizes; distance; card read speed; interference
- **Checks**:
  1. Video resolution setting (1440P/1080P files are large)
  2. Distance from camera
  3. Whether using card reader directly would be faster
- **Fixes**:
  1. For faster transfer: remove card, use ROVE USB Type-C Card reader or PC/Mac slot [manual: r3-manual-website-files]
  2. Reduce distance between phone and camera
  3. Close other apps using bandwidth
- **Escalate**: If direct card read is also slow (indicates card issue)
