# ROVE R2-4K (newer, USB-C power) — knowledge pack

## How to recognise this model

Physical cues:
- USB Type-C power port (not Mini-USB) [manual: User Manual For New R2-4K]
- 2.4" IPS display [manual: User Manual For New R2-4K]
- LED status indicator above the display [manual: User Manual For New R2-4K]
- Built-in GPS (labeled on unit) [manual: User Manual For New R2-4K]
- Serial number label on mount latch [manual: User Manual For New R2-4K]

On-screen cues:
- Wi-Fi network name pattern: "ROVE_R2-4K_*******" [manual: User Manual For New R2-4K]
- Home screen shows: Video mode icon, resolution (e.g., "4KP30"), loop recording timer, parking mode indicator, G-sensor icon, microphone indicator, emergency video lock, memory card indicator, current time/date, live speed, compass direction [manual: User Manual For New R2-4K]

Button layout:
- Power button (16)
- Menu/Mode button (9) — press once for menu, long press 2 seconds to switch modes
- UP button (10) — mute shortcut, scroll up
- Down button (12) — LCD on/off shortcut, scroll down
- Emergency Lock button (13) — lock current video, long press 2 seconds for Wi-Fi on/off
- OK/Confirm button (11) — start/stop recording, play/pause, confirm settings
- Reset button (4) — on bottom of unit [manual: User Manual For New R2-4K]

Differences from other Rove models:
- Uses USB-C power (other models may use Mini-USB) [manual: User Manual For New R2-4K]
- Newer R2-4K specifically lists "ROVE Ultimate USB Type-C Hardwire Kit" as required for parking mode [manual: User Manual For New R2-4K]
- Features "WiFi 6" specifically noted [manual: User Manual For New R2-4K]

## Key facts

- **Power and supercapacitor:** Uses supercapacitor (not battery). Holds charge for ~2 seconds to save last video file when power disconnects. Must stay plugged in for operation. Operating temperature: -4°F to 140°F (-20°C to 60°C) [manual: User Manual For New R2-4K]
- **Memory card requirements:** microSD card, Class 10, U3 speed or higher, up to 512GB max. Recommended: ROVE Ultimate or ROVE PRO cards. Sources specifically warn against Samsung and SanDisk cards [manual: User Manual For New R2-4K]
- **Video resolutions:** 4K 3840x2160 @30fps, 2K 2560x1440 @30fps, 1080P 1920x1080 @60fps, 1080P 1920x1080 @30fps [manual: User Manual For New R2-4K]
- **Wi-Fi:** Built-in WiFi 6 at 2.4GHz. Range approximately 10 meters with no obstructions [manual: User Manual For New R2-4K]
- **GPS:** Built-in GPS for geo-tagging and automatic date/time setting via GMT/UTC timezone [manual: User Manual For New R2-4K]
- **Parking mode requirements:** Requires ROVE Ultimate USB Type-C Hardwire Kit (not included). Three modes available: Time-Lapse 1fps & G-Sensor, Motion Detection & G-Sensor, or Collision Detection Only [manual: User Manual For New R2-4K]

## How-to procedures

### Power on/off

**Auto power on:** Camera turns on and starts recording automatically when it receives power (e.g., car engine started) [manual: User Manual For New R2-4K]

**Auto power off:** Camera stops recording, saves last video file, and turns off automatically within 1-2 seconds when power disconnects (e.g., car key turned to LOCK position) [manual: User Manual For New R2-4K]

**Manual power on:** Press the Power button (16) once [manual: User Manual For New R2-4K]

**Manual power off:** Press and hold the Power button (16) for 3 seconds [manual: User Manual For New R2-4K]

### Format the memory card

**DESTRUCTIVE** — All data will be deleted.

1. Press OK (11) to stop video recording first or clear any error message [manual: User Manual For New R2-4K]
2. Press the Menu/Mode button (9) once to enter Video Settings [manual: User Manual For New R2-4K]
3. Press the Menu/Mode button (9) again to switch to System Settings [manual: User Manual For New R2-4K]
4. Press the Down button (12) to scroll down until you see "FORMAT" [manual: User Manual For New R2-4K]
5. Press the OK button (11) to enter the format submenu [manual: User Manual For New R2-4K]
6. Press the Down button (12) to highlight "FORMAT" [manual: User Manual For New R2-4K]
7. Press the OK button (11) to confirm formatting [manual: User Manual For New R2-4K]
8. Press the Menu/Mode button (9) to exit settings [manual: User Manual For New R2-4K]

### Reset to defaults (software)

**DESTRUCTIVE** — All settings will be lost and restored to factory defaults. Videos are NOT deleted.

1. Go to System Settings [manual: User Manual For New R2-4K]
2. Scroll down until you see "DEFAULT SETTINGS" [manual: User Manual For New R2-4K]
3. Select "OK" to confirm [manual: User Manual For New R2-4K]

### Reset hardware (when frozen)

Press the RESET button (4) on the bottom of the camera once with a paper clip or pen tip while camera is turned ON. Camera will restart [manual: User Manual For New R2-4K]

### Set date/time and time zone

**Option 1 — Manual date/time:**
1. Go to System Settings > Date/Time [manual: User Manual For New R2-4K]
2. Select date and time of your choice [manual: User Manual For New R2-4K]

**Option 2 — Automatic via GPS time zone (recommended):**
1. Go to System Settings > GPS Time Zone Setting [manual: User Manual For New R2-4K]
2. Select your GMT/UTC value (e.g., Pacific Time Zone = GMT -8:00 or -7:00 depending on daylight saving) [manual: User Manual For New R2-4K]
3. Press OK to confirm [manual: User Manual For New R2-4K]
4. Wait for GPS signal lock — date and time will set automatically when GPS signal is received [manual: User Manual For New R2-4K]

**Note:** GPS Time Zone automatically sets to OFF if you manually set date/time [manual: User Manual For New R2-4K]

### Connect to phone app over Wi-Fi

1. **Install app:** Search "ROVE" in App Store or Google Play Store, download and install [manual: User Manual For New R2-4K]

2. **Sign up (first time only):** Create free ROVE account. Requires internet connection. Stay logged in [manual: User Manual For New R2-4K]

3. **Turn on camera Wi-Fi:** Long press the Emergency Lock button (13) for 2 seconds, OR go to System Settings to turn ON Wi-Fi [manual: User Manual For New R2-4K]

4. **Connect phone to camera Wi-Fi:**
   - Open ROVE app, click "Connect to ROVE Dash Cam WiFi" button [manual: User Manual For New R2-4K]
   - Look for Wi-Fi network named "ROVE_R2-4K_*******" [manual: User Manual For New R2-4K]
   - Join using default password: **12345678** (shown on camera screen) [manual: User Manual For New R2-4K]

5. **Android extra step:** When "No Internet" appears, wait 10-15 seconds for popup, then select "Don't ask again" and "YES" or "Always Connect" to stay connected [manual: User Manual For New R2-4K]

6. **iPhone:** "No Internet Connection" message is normal — ignore it. Look for blue check mark confirming connection [manual: User Manual For New R2-4K]

7. **Return to app:** Open ROVE app, select "R2-4K" model, proceed to access recordings [manual: User Manual For New R2-4K]

### Download/playback footage

**On camera directly:**
1. Press and hold Menu/Mode button (9) for 2 seconds to switch from Video mode to Photo mode [manual: User Manual For New R2-4K]
2. Press and hold Menu/Mode button (9) again to switch from Photo mode to Playback mode [manual: User Manual For New R2-4K]
3. Use Up (10) and Down (12) buttons to scroll through videos [manual: User Manual For New R2-4K]
4. Press OK (11) to play video [manual: User Manual For New R2-4K]

**On PC/Mac via USB:**
1. Connect camera using included short USB Type-C data cable [manual: User Manual For New R2-4K]
2. On camera screen, select "Connect as USB Flash Drive" [manual: User Manual For New R2-4K]
3. Find drive on computer, open "R2-4K" folder for normal videos, "EVENT" folder for locked videos [manual: User Manual For New R2-4K]

**On PC/Mac via card reader:**
1. Remove microSD card (camera must be OFF) [manual: User Manual For New R2-4K]
2. Insert into PC/Mac directly or use card reader [manual: User Manual For New R2-4K]

**On smartphone via Wi-Fi:**
1. Turn on camera Wi-Fi and connect phone to "ROVE_R2-4K_*******" network [manual: User Manual For New R2-4K]
2. Open ROVE app, select correct model, access recordings [manual: User Manual For New R2-4K]

**Recommended video player:** VLC Media Player (free at www.videolan.org) [manual: User Manual For New R2-4K]

### Lock/protect a file

**While recording video:**
- Press the Emergency Lock button (13) once to lock current loop cycle video file — it will NOT be deleted by loop recording [manual: User Manual For New R2-4K]

**In Playback mode:**
1. Enter Playback mode [manual: User Manual For New R2-4K]
2. Press Menu/Mode button (9) once to enter Playback Settings [manual: User Manual For New R2-4K]
3. Press Down button (12) to access Play settings [manual: User Manual For New R2-4K]
4. Scroll to "PROTECT" [manual: User Manual For New R2-4K]
5. Options: Lock Current, Unlock Current, Lock All, Unlock All [manual: User Manual For New R2-4K]

**Unlocking required before deletion:** To delete a locked/protected video, you must unlock it first in Playback Settings > Protect [manual: User Manual For New R2-4K]

### Enable parking mode

**Requirements:** ROVE Ultimate USB Type-C Hardwire Kit must be purchased separately and properly installed to car fuse box [manual: User Manual For New R2-4K]

**Options available in Video Settings > 24-HR Auto Parking Mode:**

- **OFF** [manual: User Manual For New R2-4K]
- **Time-Lapse 1fps & G-Sensor** — records time-lapse at 1fps; if impact detected, records 1-min continuous video, saves to EVENT folder, returns to time-lapse [manual: User Manual For New R2-4K]
- **Motion Detection & G-Sensor** — camera idle with LCD off, records when motion detected; if impact detected, records 1-min continuous video to EVENT folder [manual: User Manual For New R2-4K]
- **Collision Detection Only** — camera turns OFF but senses impact; if impact detected, turns ON, records 1-min video, saves to EVENT folder, turns OFF [manual: User Manual For New R2-4K]

**After activation alert:** When parking mode was activated, camera shows popup and voice alert "Parking Mode Got Activated While You Were Away" — press OK to acknowledge, then check locked videos [manual: User Manual For New R2-4K]

**Note:** GPS and Wi-Fi automatically turn off during parking mode to save power [manual: User Manual For New R2-4K]

### Motion detection (parking mode)

See "Motion Detection & G-Sensor" option under 24-HR Auto Parking Mode above [manual: User Manual For New R2-4K]

### G-sensor settings

Location: Video Settings > G-Sensor [manual: User Manual For New R2-4K]

**While recording:** When triggered by physical/gravitational force, current video file is locked and protected from loop deletion [manual: User Manual For New R2-4K]

**Parking mode G-sensor levels:** 1 (lowest, most sensitive) to 9 (highest, least sensitive). Level 5 = medium impact. Level 1 triggers on minor vibrations like closing car door; Level 9 requires larger impact [manual: User Manual For New R2-4K]

**Warning:** Locked videos still subject to deletion when event folder reaches 30% allocation — oldest locked video deleted first [manual: User Manual For New R2-4K]

### Loop recording

Location: Video Settings > Loop Recording [manual: User Manual For New R2-4K]

Options: OFF - 4GB MAX, 1-MIN (default), 3-MIN, 5-MIN, 10-MIN [manual: User Manual For New R2-4K]

**How it works:**
- Splits videos into selected length [manual: User Manual For New R2-4K]
- When normal + event videos exceed 90% of card capacity, oldest files deleted automatically [manual: User Manual For New R2-4K]
- Normal videos: 60% allocation; Event videos: 30% allocation [manual: User Manual For New R2-4K]
- If event folder < 30%, normal videos can use unused space until 90% reached [manual: User Manual For New R2-4K]
- When event folder reaches 30%, oldest locked video deleted to make room [manual: User Manual For New R2-4K]

**OFF setting warning:** Records single 4GB files until card full, then stops with "Card Full" message — will not record further until files deleted or card formatted [manual: User Manual For New R2-4K]

### Audio on/off

Location: Video Settings > Record Audio [manual: User Manual For New R2-4K]

Options: ON (default), OFF [manual: User Manual For New R2-4K]

**Shortcut:** Press UP button (10) once while recording to mute/un-mute microphone [manual: User Manual For New R2-4K]

### Firmware update

1. Connect R2-4K to ROVE app using Wi-Fi feature [manual: User Manual For New R2-4K]
2. In app, click "Firmware Update" from left navigation menu while connected [manual: User Manual For New R2-4K]
3. Follow on-screen directions to complete update [manual: User Manual For New R2-4K]

**Note:** Use the latest firmware from Rove's firmware page [manual: User Manual For New R2-4K]

## Troubleshooting playbook

### Wi-Fi: phone joins camera Wi-Fi then drops / "no internet"

**Likely causes:**
1. Android phone not confirming "stay connected" option when "No Internet" appears [manual: User Manual For New R2-4K]
2. Wi-Fi set to "ON - Once" instead of "Always On" in camera settings [manual: User Manual For New R2-4K]

**Checks/fixes:**
- **Android:** After connecting to "ROVE_R2-4K_*******", wait 10-15 seconds for popup, tap "Don't ask again" and select "YES" or "Always Connect" [manual: User Manual For New R2-4K]
- **iPhone:** "No Internet Connection" is normal — ignore and proceed to app [manual: User Manual For New R2-4K]
- Set Wi-Fi to "Always On" in System Settings > WiFi so it stays on after restart [manual: User Manual For New R2-4K]

**Escalate:** If customer cannot see the Android popup or connection still drops after confirming settings

### Wi-Fi: camera Wi-Fi not in the list

**Likely causes:**
1. Wi-Fi feature not turned on in camera [manual: User Manual For New R2-4K]
2. Camera not powered on [manual: User Manual For New R2-4K]

**Checks/fixes:**
- Verify camera is powered on (red LED solid or blinking) [manual: User Manual For New R2-4K]
- Turn on Wi-Fi: Long press Emergency Lock button (13) for 2 seconds, OR go to System Settings > WiFi > ON [manual: User Manual For New R2-4K]
- Check phone is within 10 meters with no obstructions [manual: User Manual For New R2-4K]
- Restart camera and try again [manual: User Manual For New R2-4K]

**Escalate:** If Wi-Fi still not broadcasting after confirmed powered on and Wi-Fi enabled

### Wi-Fi: password rejected

**Likely cause:** Entering wrong password

**Check/fix:**
- Default password is **12345678** — verify exactly this, no spaces [manual: User Manual For New R2-4K]
- Password is displayed on camera screen when Wi-Fi is enabled [manual: User Manual For New R2-4K]

**Escalate:** If password definitely correct and still rejected

### Wi-Fi: connection drops repeatedly

**Likely causes:**
1. Wi-Fi range exceeded (10 meters) [manual: User Manual For New R2-4K]
2. Obstructions between phone and camera [manual: User Manual For New R2-4K]
3. Phone switching to cellular data due to "no internet" detection [manual: User Manual For New R2-4K]
4. Wi-Fi set to "ON - Once" [manual: User Manual For New R2-4K]

**Checks/fixes:**
- Move closer to camera, ensure line of sight [manual: User Manual For New R2-4K]
- Android: ensure "Always Connect" selected for "No Internet" popup [manual: User Manual For New R2-4K]
- Set Wi-Fi to "Always On" in System Settings [manual: User Manual For New R2-4K]

**Escalate:** If issues persist with the phone right next to the camera and a clear line of sight

**Likely causes:**
1. High video bitrate (large file sizes) [manual: User Manual For New R2-4K]
2. 4K resolution files [manual: User Manual For New R2-4K]

- Use screen brightness "Low" to reduce heating [manual: User Manual For New R2-4K]

**Escalate:** If camera shuts down at normal temperatures

## Safety and data-loss warnings

**Heat and temperature:**

- Do not expose to excessive heat, fire, or direct sunlight in locked car for extended periods [manual: User Manual For New R2-4K]

**Power safety:**
- **Never** connect directly to vehicle 12V/24V battery — must use ROVE supplied USB-C car charger or ROVE Ultimate USB Type-C Hardwire Kit [manual: User Manual For New R2-4K]
- Do not use damaged power cords [manual: User Manual For New R2-4K]

**Mounting safety:**
- Do not install where it blocks driver's view or airbag deployment [manual: User Manual For New R2-4K]
- Do not mount on dot-matrix pattern on windshield — suction will fail [manual: User Manual For New R2-4K]
- Do not place loose on dashboard or in front of airbags [manual: User Manual For New R2-4K]
- Avoid side curtain airbag areas when routing cables [manual: User Manual For New R2-4K]

- Do not remove microSD card while camera is ON — causes write protection, data loss, or card damage [manual: User Manual For New R2-4K]
- Inspect memory card for physical damage before use — damaged cards can short-circuit [manual: User Manual For New R2-4K]
- Company NOT responsible for loss of any data or content during operation [manual: User Manual For New R2-4K]

**Recording reliability:**
