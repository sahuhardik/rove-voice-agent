## Key facts

- **Power/battery**: Supercapacitor — no battery; enhances durability and temperature resilience, but prolonged direct sunlight in hot car still affects longevity [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
- **Memory card requirements**: 128GB ROVE PRO microSD included; supports up to 1TB; use only high-quality compatible cards (ROVE PRO or ROVE Ultimate recommended); format at least monthly to prevent corruption [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
- **Video resolutions**: 4K 2160P front, 1080P rear [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
- **Wi-Fi band**: Dual band 5G + 2.4GHz; 5G provides ~20MBps download speeds [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
- **GPS**: Built-in; records location and speed data embedded in video [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
- **Parking mode requirements**: Requires ROVE Ultimate 3-Lead Type-C Hardwire Kit; auto-triggers when car turned off; detects motion or collision; professional installation recommended for hardwire kit [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
- **Operating temperature**: Not explicitly stated; supercapacitor withstands extreme temperatures but prolonged direct sunlight in hot car affects longevity [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]

## How-to procedures

### Power on/off
1. **Power on**: Connect USB-C power cable to dash cam and power source (car charger or hardwire kit); automatically powers on when vehicle ignition turns on [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
2. **Power off**: Disconnect power cable, or vehicle ignition off (if not using hardwire kit for parking mode) [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
3. **Force restart**: Press and hold the power button [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]

### Format the card **DESTRUCTIVE** — erases all footage
1. Press 'MENU' button to access settings [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
2. Use arrow buttons to navigate to format option [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
3. Press 'OK' to confirm [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
- Format monthly to maintain performance and prevent corruption [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]

### Reset to defaults **DESTRUCTIVE** — all custom settings lost
- Procedure not specified in sources — see "Not covered"

### Set date/time and time zone
- Exact steps not specified in sources — see "Not covered"

### Connect to phone app over Wi-Fi
1. Download ROVE App on smartphone (iOS/Android) [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
2. Connect phone to dash cam's Wi-Fi network (5G/2.4GHz dual band) [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
3. Open ROVE App to manage settings and view footage [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]

### Download/playback footage
**Via App:**
1. Connect to dash cam Wi-Fi as above [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
2. In ROVE App: view live feed; play back recorded footage; download videos directly to phone [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]

**Via PC/Mac:**
1. Remove microSD card and use with computer, OR use 1M USB Type-C Data Cable [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
2. Use ROVE Dash Cam GPS Player software to view recordings with GPS logs and G-Sensor data [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]

### Lock/protect a file
1. **Manual lock**: Press the emergency lock button to manually lock current footage [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
2. **Automatic lock**: G-sensor detects sudden impact/collision and automatically locks current video segment to prevent overwrite [manual: ROVE R2-4K Dual Dash Cam Instruction Manual]
